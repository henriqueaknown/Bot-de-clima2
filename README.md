# 🤖 Discord Weather & Voice Bot

O **Discord Weather & Voice Bot** é uma solução desenvolvida em Python para integração entre o Discord, serviços meteorológicos, síntese de voz e ferramentas de entretenimento.

O sistema permite que usuários consultem informações meteorológicas diretamente pelo Discord, recebendo dados como **temperatura, sensação térmica, umidade, velocidade do vento e condições climáticas**.

Além das informações meteorológicas, o projeto possui um sistema de **previsão do tempo**, permitindo consultar as condições previstas para os próximos dias.

A aplicação também conta com recursos de **síntese de voz**, possibilitando a reprodução de textos e informações meteorológicas por áudio, além de permitir o controle da velocidade da fala e a consulta das vozes disponíveis no sistema.

O bot também oferece ferramentas de administração e consulta, como informações sobre o servidor, informações dos usuários e medição da latência da aplicação.

Para tornar a experiência mais interativa, foram adicionados recursos de entretenimento, incluindo **cara ou coroa, dados, números aleatórios e um sistema de respostas baseado em perguntas**.

O projeto combina **automação, integração com APIs, comunicação em tempo real, processamento de voz e sistemas interativos**, demonstrando a aplicação do Python na criação de soluções multifuncionais para o Discord.
